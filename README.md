<h1>For what?</h1>
<p>Utility for converting xml files to json.</p>
<img src="readmedata\for_what.png" />
</div>

<div>
<h1>How to compile?</h1>
<p>Use sh-script 'compile.sh' in root directory.</p>
</div>

<div>
<h1>How to use?</h1>
<p>In console (cmd, bash etc.): "./fxmltjson.exe xml_files..."</p>
<p></p>
<h2>Example: </h2>
<p>In work directory have two files: file1.xml and file2.xml.</p>
<p>In console writes: ./fxmltjson.exe file1.xml file2.xml.</p>
<p>If all files valid, You can see file1.json and file2.json in work directory and this messages: </p>
<img src="readmedata\use.png" />
</div>

<div>
<h1>Technical agreements</h1>
<p>1. Skips all tag attributes.</p>
<p>2. Skips all comments.</p>
<p>3. Skips all information tags, which starts with '!' or '?'.</p>
<p>4. This is study project.</p>
